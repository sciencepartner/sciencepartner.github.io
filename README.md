# 科学伙伴 (SciencePartner) - 高端科学内容品牌网站

## 项目概述
这是一个为"科学伙伴"内容品牌创建的高端、克制、国际化审美静态网站。网站定位为现代科学杂志与知识品牌官网的结合体，专注于深度科学内容的展示与传播。

## 设计理念
- **高级杂志感**：像一本来自未来的中文科学杂志
- **内容优先**：为深度阅读优化，克制装饰
- **国际化审美**：现代、简洁、有秩序
- **品牌塑造**：建立高端科学内容品牌形象

## 技术栈
- 纯HTML5 / CSS3 / JavaScript (ES6+)
- 无框架依赖，轻量高效
- 响应式设计，移动优先
- GitHub Pages友好部署

## 设计系统

### 配色方案
- 主背景: #F9F9F7 (象牙白)
- 主文字: #2C2C2C (墨灰)
- 点缀色: #1A365D (深海军蓝)
- 链接色: #2B6CB0 (深蓝)

### 字体系统
- 中文标题: 思源宋体 / 霞鹜文楷
- 中文正文: 思源黑体 / 系统黑体
- 英文标题: Georgia / Times New Roman
- 英文辅助: Inter / -apple-system

### 间距系统 (基于8px)
- 大间距: 64px
- 中间距: 32px
- 小间距: 16px
- 微间距: 8px

## 页面说明

### 首页 (Home)
- Hero首屏：品牌展示与核心主张
- 代表稿件：3-6篇精选文章
- 栏目入口：主要栏目介绍
- 品牌说明：品牌定位宣言
- 最新文章：最近更新内容
- 专题策划：重点专题展示

### 文章页 (Essays)
- 分类筛选：按主题浏览
- 文章卡片：高质量展示
- 精选/最新切换：内容组织
- 分页导航：浏览控制

### 单篇文章页 (Article)
- 阅读优化：最佳行宽与字号
- 内容层次：清晰标题结构
- 相关推荐：智能内容关联
- 阅读进度：增强体验

### 栏目页 (Columns)
- 栏目总览：所有栏目介绍
- 单栏目页：栏目专属内容
- 编辑策划感：不同于普通分类

### 关于页 (About)
- 品牌故事：定位与使命
- 关注议题：内容方向说明
- 主理人介绍：专业克制风格
- 联系方式：简洁自然

## 开发说明

### 本地开发
1. 克隆仓库
2. 使用任何静态服务器（如 `python3 -m http.server`）
3. 打开 `http://localhost:8000`

### 部署
1. 推送到GitHub仓库
2. 启用GitHub Pages
3. 配置自定义域名（sciencepartner.com.cn）

### 内容更新
- 文章：编辑 `data/articles.json`
- 栏目：编辑 `data/columns.json`
- 专题：编辑 `data/features.json`

## 设计原则
1. **克制装饰**：形式服务于内容
2. **阅读优先**：为长文阅读优化
3. **品牌一致**：统一视觉语言
4. **响应友好**：全设备适配
5. **性能优先**：快速加载体验

## 目标效果
最终网站应让人感受到：
- 这不是普通博客或模板站
- 有明显的高级杂志气质
- 适合展示深度科学稿件
- 符合"科学伙伴"的内容野心
